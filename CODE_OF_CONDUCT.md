# Community Code of Conduct

We welcome people of all backgrounds and experience levels. Be respectful, patient and constructive. Critique ideas and code, explain evidence, and accept corrections.

Harassment, discrimination, threats, personal attacks, sexualized content, doxxing and publication of private network information or credentials are unacceptable. Do not pressure people to disable security protections or share sensitive diagnostics.

Maintainers may edit or remove violating content, limit participation or block repeated/severe offenders. Decisions should be proportionate and protect affected people. If you experience a violation, contact the maintainer through the contact methods available on [hhhoratioxu's GitHub profile](https://github.com/hhhoratioxu). Do not expose private details in a public issue. For software vulnerabilities use [SECURITY.md](SECURITY.md).

This code applies to repository issues, pull requests, discussions and other project spaces.
